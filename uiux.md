# RicozViz — UI/UX Design Specification

## 1. Design Direction

RicozViz should look like a premium enterprise analytics product.

Design characteristics:

- Premium
- Minimal
- Modern
- Technical
- Enterprise-grade
- Data-focused
- Clean
- Professional

The interface must feel like a real SaaS product, not a student project or generic dashboard template.

---

## 2. Avoid

Do NOT use:

- Excessive gradients
- Generic AI landing page aesthetics
- Excessive glassmorphism
- Excessive rounded cards
- Stock photography
- Cartoon illustrations
- Unnecessary animations
- Huge decorative elements
- Overly colorful dashboards

Use color primarily to communicate information.

---

## 3. Visual Language

Use:

- Strong typography
- Generous whitespace
- Subtle borders
- Clean cards
- Structured grids
- Professional data visualizations
- Subtle shadows
- Consistent spacing

---

# 8. AI Analyst UI

Use a chat-style interface.

Left:

Conversation

Right:

Generated chart/data visualization

Example:

User:
"Why did revenue fall last quarter?"

AI response:

Revenue declined 12.4%.

Main contributors:

Karnataka: -21%
Product A: -32%
Enterprise segment: -18%

Include "View Analysis" action.

# 10. Responsive Design

Desktop:
Full sidebar + dashboard workspace.

Tablet:
Collapsible sidebar.

Mobile:
Bottom navigation or collapsible navigation.

Charts must resize intelligently.

Tables should support horizontal scrolling.

---

# 11. Animation

Use subtle animations only.

Examples:

- Page transitions
- Card hover
- Chart loading
- Sidebar transitions
- Modal transitions
- AI response animation

Avoid excessive motion.

---

# 12. States

Every important component must support:

- Loading
- Empty
- Error
- Success
- Disabled
- Hover
- Focus

Example:

"No dashboards yet"

"Create your first dashboard"
